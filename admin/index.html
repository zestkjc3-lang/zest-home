홈페이지 편집

메인 배너 · 공지 카드 · 강사진을 홈페이지 화면을 보면서 바로 고칠 수 있어요.
처음 한 번만 아래 칸에 토큰(비밀번호 같은 글자)을 붙여넣으면 돼요.

토큰은 어떻게 만드나요?
  1. GitHub 로그인 → 오른쪽 위 프로필 → Settings
  2. 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. Repository access: Only select repositories → zest-home
  4. Permissions → Contents: Read and write (나머지는 그대로)
  5. 만들어진 토큰을 복사해 위 칸에 붙여넣기
공용 컴퓨터에서는 「로그인 유지」를 끄고 쓰세요.

사용법

홈페이지 미리보기와 수정 칸이 함께 보여요. 고친 내용은 미리보기에 바로 보이고, 「저장하기」를 눌러야 실제 홈페이지에 올라가요.

✏️ 고치기

  1. 홈페이지 화면(미리보기)에서 바꾸고 싶은 배너 · 공지 카드 · 강사 카드의 「✏️ 수정」 버튼을 누르세요. 오른쪽 목록의 「✏️ 수정」을 눌러도 돼요.
  2. 버튼이 아닌 곳을 누르면 실제 홈페이지처럼 이동해요(상세 페이지·글·강사 프로필). 다른 페이지로 갔다면 위의 「← 홈페이지 미리보기로」로 돌아와요.
  3. 오른쪽에 수정 칸이 열려요. 글자를 고치면 미리보기에 바로 반영돼요.
  4. 다 고쳤으면 오른쪽 위 초록색 「저장하기」를 누르세요. 1~2분 뒤 홈페이지에 반영돼요.

🖼 사진 바꾸기 · 내려받기

  • 사진 바꾸기: 컴퓨터나 휴대폰에서 새 사진을 고르면 끝이에요. 너무 큰 사진은 자동으로 알맞게 줄여요.
  • 사진 다운로드: 지금 걸려 있는 사진을 내 컴퓨터에 저장해요. 수정 전 원본을 보관할 때 쓰세요.
  • 배너는 가로 사진(약 1024 × 716), 공지 카드는 정사각형, 강사는 세로 사진이 잘 맞아요.

↕️ 순서 바꾸기

  • 오른쪽 목록에서 왼쪽 ⠿ 손잡이를 잡고 위아래로 끌어다 놓으세요.
  • 맨 위에 있는 것이 홈페이지에서도 첫 번째로 보여요.

✍️ 글 쓰기 (카드·배너를 누르면 열리는 글)

  1. 카드나 배너 수정 칸의 「누르면 이동할 페이지」 아래 「✏️ 새 글 쓰고 여기에 연결하기」를 누르세요. (위의 「✍️ 글 쓰기」 탭에서 먼저 써도 돼요)
  2. 미리보기가 글 페이지로 바뀌어요. 제목, 대표 사진, 본문을 쓰면 바로 보여요.
  3. 본문은 「+ 문단」, 「+ 사진」, 「+ 소제목」 같은 버튼으로 하나씩 쌓아요. 글자를 드래그하고 「굵게」, 「형광펜」을 누르면 꾸밀 수 있어요.
  4. 이미 쓴 글은 「누르면 이동할 페이지」 목록의 「✍️ 내가 쓴 글」에서 골라 연결할 수 있어요.

➕ 추가 · 🗑 삭제

  • 목록 맨 아래 「+ 새 ○○ 추가」를 누르고 사진과 글을 넣으세요.
  • 지우려면 목록의 「🗑 삭제」를 누르세요.
